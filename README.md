# Kigoo

Kigoo est un jeu d’observation : retrouve toujours le lion orange parmi les autres lions.

Le jeu progresse sur 300 tableaux avec une difficulté croissante, des déplacements, des clignotements et différents effets de jeu.

Ce dépôt correspond à Kigoo et n’a aucun rapport avec l’ancien jeu Bibit.
